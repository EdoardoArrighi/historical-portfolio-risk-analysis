# Historical Portfolio Risk Analysis

## 1. Project Overview

This project aims to analyse the historical risk characteristics of a multi-asset investment portfolio using Python and quantitative finance methodologies.

The analysis applies the portfolio's current asset allocation retrospectively to historical market data, from October 17, 2023 to November 10, 2026.

**Important:** This is a hypothetical historical simulation based on current portfolio weights. It does not represent the actual historical performance of the investment portfolio.

## 2. Objectives

- Analyse a multi-asset portfolio.
- Retrieve and process historical market prices.
- Convert asset prices into EUR.
- Calculate daily asset returns.
- Study correlations and covariance between assets.
- Construct a theoretical portfolio.
- Evaluate historical performance and drawdowns.
- Estimate portfolio risk using VaR and CVaR.
- Compare portfolio performance against a benchmark.

## 3. Methodology

The analysis will follow these steps:

1. Data import and cleaning.
2. Asset and ticker identification.
3. Historical market data collection.
4. Currency conversion.
5. Daily returns calculation.
6. Descriptive statistical analysis.
7. Correlation and covariance analysis.
8. Portfolio construction.
9. Performance and drawdown analysis.
10. VaR and CVaR estimation.
11. Benchmark comparison.

## 4. Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- SciPy
- yfinance

## 5. Repository Structure

- `notebooks/`: quantitative analysis and visualizations.
- `data/`: input and processed datasets.
- `reports/`: analytical outputs and figures.

## 6. Disclaimer

This project is for educational and research purposes only. The results represent a hypothetical historical simulation and should not be interpreted as actual investment performance or financial advice.
